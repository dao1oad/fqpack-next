# CLX 买卖信号闭环配对回测方案（单模型 + 18×18 跨模型）

日期：2026-07-24。数据：run `01KBYC7REC0V3RY99634853AAB` 封存逐笔 event_outcomes（只读），2005-2023（TRAIN+VALIDATION），不触碰 HOLDOUT。

## 1. 交易规则（事件配对）

- **开仓**：股票 X 在 T 日出现"买入模型 A"的买入信号（reveal_date=T），T+1 开盘价（raw_entry_open）买入；
- **平仓**：持仓期间同一股票 X 出现"卖出模型 B"的卖出信号（reveal_date=T2>T），T2+1 开盘价卖出；
- **超时退出**：若 60 个自然日内未出现卖出信号，按 20 日 horizon 收益退出（用 h20_raw_return 近似）；
- 同一股票持仓期间的重复买入信号忽略（不加仓）；平仓当日的新买入信号可重新开仓；
- 收益 = 卖出信号事件的 raw_entry_open / 买入事件的 raw_entry_open - 1（同一复权口径下的开盘到开盘收益，需校验复权因子跳变）；
- 单模型策略即 A=B；跨模型组合遍历 A×B ∈ 18×18=324 种。

## 2. 统计口径

- 分 TRAIN（2005-2019）/ VALIDATION（2020-2023）分别统计（跨段的持仓丢弃）；
- 指标：交易笔数、平均持有天数、单笔平均收益、胜率、单笔收益 t 值、年化近似（等权日均滚动）、最大单笔亏损、逐年均值；
- 组合排序：先 TRAIN 选 top，VALIDATION 验证（沿用条件筛选方法论的选择/验证分离原则）；
- 基准对照：同一买入信号 + 固定 5 日/20 日持有（不用卖出信号），用来定量回答"卖出信号平仓是增益还是拖累"。

## 3. 已知限制

- 逐笔 parquet 只有各 horizon（1/3/5/10/20 日）收益，没有任意日退出价格；配对收益用"卖出事件的 entry_open / 买入事件的 entry_open"计算，两事件复权基准可能不同（adj_factor 跳变时丢弃该笔）；
- 未扣费用/冲击/涨跌停；等权逐笔均值，不含仓位容量约束；
- 全部为研究性统计，无 HOLDOUT，不构成可交易证据。
