# CLX 实盘候选策略 QFQ（前复权）回测报告

- 日期：2026-07-25
- 分支：codex/clx-backtest-platform-465（Draft PR #466）
- 性质：事后研究（post-hoc）。规则在同一数据集上反复观察后确定，存在选择性偏差；未预注册、未使用新 HOLDOUT，不构成实盘建议。

## 1. 目的

将此前的实盘候选策略（见 `2026-07-25-clx-live-strategy-candidate.md`，RAW 口径）改用**前复权（QFQ）开盘价**重新回测，并输出**逐笔交易明细**供前端展示。

## 2. 策略规则（与候选报告一致）

1. 信号池：S0016（支撑阻力区间反转）+ S0006（前低支撑回踩）买入信号；
2. 触发过滤：primary_trigger_semantic ∈ {ENGULFING, STRONG_FRACTAL}；
3. occurrence == 1（首次回踩）；
4. 市场状态开关：全市场 18 模型卖出信号 20 日滚动密度 > expanding 80 分位（min_periods=250）时暂停新开仓（无未来函数）；
5. 入场：信号日 T+1 以 QFQ 开盘价；
6. 出场：入场后第 20 个交易日以 QFQ 开盘价（时间退出，不主动止盈）；
7. 费用：双边合计 0.4%（近似，不含冲击成本）。

## 3. 数据与口径

- 事件：sealed run `01KBYC7REC0V3RY99634853AAB` 逐笔 event_outcomes（ELIGIBLE × EXECUTABLE，TRAIN+VALIDATION，2005–2023；HOLDOUT 未触碰）；
- 行情：sealed QFQ snapshot `cf579f3b…` 的 `qfq_open`（信号计算与成交价同为 QFQ 口径，`ENGINE_INPUT_PRICE_DOMAIN = QFQ_OHLC_RAW_VOLUME`）；
- 事件 4,022,716 笔 → 过滤后 4,458 笔，QFQ 日线 12,713,966 根，入场日 QFQ 匹配缺失 0；
- 脚本：`strategy_qfq.py`（容器 fq_clx_backtest_worker 内运行，只读 sealed 数据），输出 `/tmp/strategy_qfq.json`。

### 停牌跨越提示

「第 20 个交易日」按个股实际交易日计。39 笔交易期间长期停牌，日历跨度远超 20 日（最大一笔 000650，2006-04 股改停牌一年，+1288%）。剔除这 39 笔后整体均值 +2.99%（VALIDATION 不受影响，仍 +5.83%）。QFQ 口径高于此前 RAW 口径（+2.82%）主要来自复权收益还原与上述停牌长持样本。

## 6. 限制

- 事后研究，选择性偏差不可消除；正式实盘前须按 AGENTS.md 流程预注册合同 + 新 HOLDOUT 一次性检验；

- 停牌跨越样本会拉长实际资金占用期，实盘不可复制其收益节奏。
