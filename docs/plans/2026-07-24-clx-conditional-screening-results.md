# CLX 全模型条件筛选结果 + 卖出方向语义修正

日期：2026-07-24。方法论见 `2026-07-24-clx-conditional-screening-methodology.md`。数据：run `01KBYC7REC0V3RY99634853AAB` 封存逐笔 event_outcomes（ELIGIBLE × EXECUTABLE × h5_status=OK，2005-2023 共 3,959,110 笔），只读。

## 0. 重要修正：此前报告的卖出方向解读被反向

核对源码后确认（`event_study.py` `DIRECTION_ADJUSTED_RETURN_CONTRACT = "direction * (raw_exit_close / raw_entry_open - 1)"`，`build_event_metrics_frame` 与 `ranking.py` 的 mean_return 均直接取 `direction_adjusted_return`）：

- `event_metrics.mean` 与冻结排行 `mean_return` **本身已是方向调整后收益**（正 = 预测正确）；
- 此前两份报告（18 模型评价、模型×方向统计）与可视化对卖出方向又乘了一次 direction，把卖出信号的边际符号翻转了。

**修正后的事实**：全部 18 个模型的卖出信号方向调整边际在 TRAIN / VALIDATION / HOLDOUT 三段全部为负（例：S0000 卖出 TRAIN -0.78%、VAL -0.38%、HOLDOUT -0.75%）。即**卖出信号发出后股价平均不跌反涨**——此前"卖出侧是主要价值（逃顶/避险）"的结论不成立，应更正为：**卖出信号是稳定的反向指标（信号后短期反弹）**。买入方向（direction=+1，调整值=原始值）不受影响，S0016 系列分析全部有效。

冻结组合④图解读同步更正：负向组合三段均为负边际 = 三段都预测错误且 HOLDOUT 更明显（反向效应在样本外持续），而非"样本外保持有效"。可视化页面已修正。

## 2. 卖出方向：条件化无法使其变为有效预测，但反向效应稳健

- 全部 36×92 个卖出条件格中，没有任何条件能让卖出信号 VAL 方向调整边际显著为正（最好的格 t≈1.0）；
- 反向看（信号后股价上涨幅度），最强且三段稳健的格：
  - S0004 卖出 occ1 × 价<20：信号后 5 日平均涨 TRAIN +0.95% / VAL +0.82%（|t|>23，VAL n=25,807）；
  - S0007 卖出 occ1 × 价<20：+0.92% / +0.77%（n=20,723）；
  - S0003 卖出 occ1：+1.31% / +0.57%；S0015 卖出 occ1 × 价<10：+0.57% / +0.55%。
- 解释：缠论卖点多在急跌/触及支撑后出现，短期均值回复导致反弹——卖出信号实为**短线超卖反弹指标**。
- 含义：(a) 不应把卖出信号当离场/避险触发（平均卖在反弹前）；(b) "卖出信号→反向做多"是全数据集中统计强度最高的候选假设，值得预注册。

## 3. 局限与下一步

- 网格受 S0016 前期分析启发，存在一次全局先验污染；TRAIN 选格含 winner's curse，VAL 复现缓解但不消除；
- 未扣费用/冲击/涨跌停；低价股子集尤其敏感；
- HOLDOUT（2024-2026）对模型×方向×条件粒度不存在，本表全部为预注册候选，非可交易证据；
- 建议新研究合同预注册：① 各模型"复现✅"条件；② 卖出信号反向做多（S0004/S0007 occ1 低价）；③ 统一低价×occ1×硬确认因子叠加多模型共振。
