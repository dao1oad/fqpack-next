# CLX 模型×触发条件 闭环回测 vs 上证指数（2026-07-25）

事后研究，只读 sealed artifacts（run `01KBYC7REC0V3RY99634853AAB`），未预注册、未用 HOLDOUT、不构成实盘建议。

## 规则

- 把每个模型的买入信号按主触发形态（`primary_trigger_semantic`）拆分为独立分组。
- 入场 = 买入信号 T+1 QFQ 开盘；退出 = 18 个模型中任一个对该股触发卖出信号后的 T+1 QFQ 开盘（与 `2026-07-25-clx-18-models-closedloop-vs-index.md` 同口径）。
- 扣 0.4% 双边费用；TRAIN(2005-2019)+VALIDATION(2020-2023)；等不到任何卖出信号的买入剔除。
- 样本数 <100 的（模型×触发）分组剔除，保留 90 组。
- 净值曲线 = 按开仓月聚合单笔收益后月度复利的等权示意曲线；基准 = 上证指数（Mongo `quantaxis.index_day` code=000001）月收盘 2005-01 归一化（2023-12 约 2.50）。

## 结论

1. **ENGULFING（吞没）是跨模型最强触发**：在 S0011/S0006/S0016/S0009/S0000 等多个模型上均居首，进一步印证「强确认」放大器结论。
2. **MACD_CROSS 在部分模型（S0013/S0011/S0000）上表现意外强**，值得纳入候选观察。
3. **MA5_TURN / PIN_BAR 样本最大但均值普遍低**，稀释了整模型的表现——按触发拆分能显著提纯买入信号。
4. 弱模型（S0012/S0003/S0007）即使拆触发也无法救回，与 18 模型闭环结论一致。
