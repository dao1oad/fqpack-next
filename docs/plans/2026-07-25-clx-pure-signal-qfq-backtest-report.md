## 与 RAW 版对比的关键变化

1. **前复权后所有长持有模型收益系统性上移**（分红送转计入）：S0016 VAL 从 +18.4% → +21.9%，胜率 79% → 84.5%；TRAIN 从 +27.8% → +48.8%。RAW 版确实低估了长持有收益。
2. **S0014 从 −20% 收窄到 −15.5%**：约 1/4 的"亏损"是 RAW 送转失真，但方向不变，仍是输家。
3. **输家结论不变**：S0004（VAL −3.4%，胜率 24.8%）、S0007、S0014、S0015 纯信号操作仍系统性亏损。
4. **TRAIN 段几乎全模型均值为正**是 2005–2019 含牛市 β + 长持有的结果，中位数为负的模型（S0002/S0004/S0005/S0007/S0010/S0014/S0015）靠少数大牛股拉均值。

## 限制（与 RAW 版相同，除复权外）

- 未扣费用/冲击；等不到卖出信号的买入被剔除（S0016 剔 26%、S0013 剔 82%，幸存者偏差）；长持有含 2020–23 小盘牛市 β；无 HOLDOUT；事后分析非预注册；单位时间收益仍低于短持有策略（S0016 ≈ 0.06%/天）。
