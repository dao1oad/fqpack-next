|---|---|---|---|
| 下跌 | 51.2% / +2.0% | 52.8% / +3.9% | 53.5% / +6.1% |
| 震荡 | 49.1% / +2.0% | 48.3% / +3.3% | 48.5% / +4.0% |

- **下跌段胜率最高**（信号本质是超跌反转）；**上涨段胜率最低但 h60/h90 净收益最高**（beta 驱动、拿得久赚得多）；震荡段介于两者且随持有期不再改善。
- **模型分化明显**：下跌段 h30 胜率最高的是 S0016×吞没 62.8%、S0006×吞没 60.8%、S0010×吞没 57.6%、S0011×吞没 57.3%、S0000×吞没 57.4%；S0006/S0016×强分型 56~58%。
- S0016×强分型在 DOWN h90 达 64.1% 胜率 / +11.5% 净收益，是全表最强单元格。
- 上涨段几乎所有模型 h30 胜率 <50%（追高吃亏），仅 S0017×吞没上涨段全持有期 >50% 且 h90 +13.3%。
- 弱模型：S0003/S0004/S0009/S0012 的强分型在多数行情胜率 <48%，无正贡献。

## 第四步：过滤条件探索（如何提高胜率）

单因子效果（全样本基线 h60 胜率 49.2%）：

| 过滤条件 | h60 胜率 | h60 净收益 | 备注 |
|---|---|---|---|
| 信号日拥挤度 Top25%（Q4） | **56.3%** | +6.8% | 最强单因子；恐慌日成批信号 |
| 入场价 <5 元 | **56.9%** | +8.6% | 单调：>20 元仅 44.5% |
| 入场价 5-10 元 | 51.5% | +5.1% | |
| 下跌行情 | 52.8% | +3.9% | |
| 双/三模型共振 | 48.8% / 48.1% | — | **在 18 模型全集下无效**（弱模型共振拖累） |
| 首次触发 | 48.8% | — | 全集下无效（4 组合子集内才有效） |

组合配方（h60）：

| 配方 | n | 胜率 | 净收益 |
|---|---|---|---|
| 共振 + <10元 | 106,909 | 52.7% | +6.1% |
| 拥挤日 + 共振 + <10元 | 76,263 | 53.4% | +6.0% |
| 下跌 + <10元 | 23,419 | 57.1% | +6.6% |
| **强模型(S0016/S0006) + 拥挤日 + 共振**（h60） | 3,115 / 7,001 | **59.2% / 56.1%** | +7.9% / +6.2% |

**高质量信号配方结论**：
1. 最有效的过滤是 **"选对模型"**——S0016、S0006 与其余 16 个模型有断层差距（h60 胜率 59%/56% vs 其它 46~51%）；
2. 其次是 **信号日拥挤度**（当日全市场信号数在 Top25% 分位）与 **低价分层**（<10 元）；
3. 行情过滤上 **下跌/震荡段的信号质量高于上涨段**（上涨段胜率反而最低）；
4. "双模型共振"与"首次触发"只在 S0006/S0016 子集内有效，放到 18 模型全集反而失效——不宜作为全局过滤。
5. 推荐配方：**S0006/S0016 × 吞没/强分型 + 下跌或震荡行情 + 入场价 <10 元 + 信号扎堆日**，h60 胜率约 57~64%、净收益 +6~11%。
