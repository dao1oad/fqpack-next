# CLX 评价页重新设计方案 v2（基本面驱动）——最终版

> 状态：已评审定稿（Devin Ultra 单轮评审 + 本机 PM/UI-UX 整合）
> 日期：2026-08-11
> 前置业务决策（已定）：用 `a-share-fundamental-analysis` 替换 `a-share-market-replay`，只保留一个分析引擎；自动任务 Phase A 改为基本面分析；前端 CLX pure-buy 结果改为按基本面排序；去掉"三池工作区"。
> 本文件为设计稿，实施完成后需将当前系统事实同步到 `docs/current/**`。

## 1. 产品定位与设计原则

**核心转变**：页面从"信号列表 + 市场复盘"升级为"基本面背书下的可投资性排序"。每一行排序都携带可下钻的证据链。

1. **排序可解释**：综合等级 → 六维等级 → 指标 → 证据来源（evidence_ids），任何排名可三层溯源。
2. **全量可及 + 深度分层**：全量 Stock buy（120~306 只/日）快排全覆盖；**快排前 100 只**进入标准单股深析；列表明确区分"深析区 / 初评区"。
3. **先看分布，再选标的**：统计面板回答"池子整体成色"，列表回答"哪只最值得看"，详情回答"这只凭什么"。

目标用户：盘后决策者（5 秒判断池子成色）、深度研究者（逐票证据链）、风控复核（排序抽查溯源）。

## 2. 自动任务改造（数据链路）

每日跑批：

```text
CLX 正式批次 (content_hash 锁定)
  → 全量快排（规则化财务等级，确定性，159 只）
  → 快排前 100 只标准单股深析（a-share-fundamental-analysis 六维评分）
  → 确定性排序（基本面排序键，脚本计算）
  → 统计聚合 fundamental-stats.json（前端零计算）
  → 发布前端产物
```

产物：

| 产物 | 内容 |
|---|---|
| `clx-fundamental-ranking.csv` | 全量行 + 六维等级 + 深析/初评标记 + 证据等级 |
| `fundamental-analysis/<symbol>.json` | 前 100 深析完整报告 |
| `fundamental-snapshot/<symbol>.json` | 后 59 初评快照 |
| `fundamental-stats.json` | 统计聚合（行业/维度/估值/风险/质量门） |

市场字段（market_lane/market_theme_id/market_fit_grade 等）从主链路与 UI 移除；业务 `primary_group` 保留为统计的行业维度。

## 4. ① 列表区：CLX 基本面排序

### 排序语义（评审修正）
- **统一排序键 = 快排综合等级**（确定性）；深析结果更新该标的等级后仍保持同一排序键口径，**前 100 行恒为深析标的**（深析名单 = 快排前 100），后 59 行恒为初评标的。
- **分区由排序自然形成**：不设"分隔条 + 混排"的中间态；深析区（前 100）正常饱和度，初评区（后 59）等级徽章降饱和并统一标注"初评"。
- 可切换排序维度：综合 / 商业质量 / 成长 / 盈利质量 / 资产负债 / 行业能力 / **估值便宜度（按 valuation_grade 行业分位等级，非原始 PE）** / 风险（升序）。
- 切换排序维度仅改变行序，**不改变深析/初评分区边界**（分区按快排等级固定，防止"换排序后深析标的不在顶部"的认知错乱）。

### 行设计（两级密度 + 虚拟滚动）
- **紧凑行**（默认）：rank、代码、名称、深析/初评徽章、综合等级徽章、六维迷你色点（hover 显等级）、关键指标（ROE/毛利率/净利增速/PE/PB）、风险标记、证据等级。
- **展开行**（点击行首展开箭头）：指标明细 + 一句话定位 + "打开详情"入口。
- 列表使用虚拟滚动（159+ 行，Element Plus 或自研窗口化），保证滚动流畅。

### 筛选
行业（业务 primary_group 多选）/ 证据等级 / 风险标记 / 分区（全部/深析/初评）/ 单维等级下限 / 搜索；**筛选、排序、选中均持久化到 URL query**（可分享、可收藏）。

## 5. ② 详情区：用户如何查看每个标的基本面

### 交互
- 点击列表行 → 详情区联动（单向下钻，不跳转）；↑↓ 键盘切换标的并**保持当前展开的分节状态**；Esc 返回列表焦点。

### 结构（评审修正：决策卡优先 + 手风琴）
- **首屏决策卡**（约一屏高度，盘后扫读 3 秒可读完）：
  - 数据快照条（as-of / 最新报告期 / 行情时点 / 证据等级）
  - 一句话定位（大字号结论）
  - 六维评分卡（六格：等级 + 一句依据）
  - 关键指标条（ROE / 毛利率 / 净利增速 / 经营现金流 / PE / PB）
  - 风险清单（高/中/低，最高 3 条）
  - 三项优势 / 三项问题
- **手风琴分节**（默认折叠，按需展开）：
  1. 业务结构与护城河（主营构成表 + 壁垒 + 依赖）
  2. 财务趋势（三年 + 最新期，Sparkline）
  3. 成长与盈利质量（支持性/竞争性解释双栏 + 异常标记）
  4. 资产负债表与资本配置（净现金/有息负债/商誉/分红回购）
  5. 行业能力与研发（行业适配指标）
  6. 估值情景（PE/PB/股息率 + 保守/基准/乐观）
  7. 验证节点（下一报告期验证指标）
  8. 证据溯源（evidence_ids 折叠区，来源 + 抓取时间）
- **初评区标的**（后 59）：决策卡 = 快照条 + 规则生成的一句话定位 + 六维等级 + 指标卡 + 证据溯源；**不展示"深析排期中"文案**（深析名单是规则设计，不是排队），统一标注"本期初评"。

## 6. ③ 统计区：多维统计分析

### 默认 4 图（评审修正：收敛默认视图）
1. **KPI 摘要卡**：均值 ROE、中位 PE、质量 A 占比、风险标记数、深析/初评数；
2. **质量 × 估值散点**：X=质量等级、Y=PE 行业分位、气泡=市值——"又好又便宜"；
3. **行业分布横条**：业务 primary_group 占比；
4. **六维等级分布**：六维各等级占比堆叠条。

### 折叠区（"更多图表"展开）
5. 成长 × 盈利四象限（净利增速 × 毛利率）；
6. 风险热力（风险标记 × 行业矩阵）；
7. 证据覆盖环形图（A/B/C/D + 深析/初评）；
8. 估值分位直方图（PE/PB 相对行业分位）。

### 联动（评审修正：单向下钻，避免状态冲突）
- 统计面板点击行业条 / 散点 → **只写入列表筛选条件**（不直接改选中、不覆盖用户已选的详情标的）；
- 列表筛选变化 → 统计面板同步高亮对应分组；
- 全屏模式：统计区可展开为全屏画布。

## 7. 交互与视觉规范

- 沿用 `--fq-*` CSS 变量 + Element Plus + ECharts 6；
- 等级配色：strong=绿 / good=蓝 / neutral=灰 / watch=琥珀 / weak=红；证据 A/B 实心、C/D 描边；
- 深析徽章实底、初评徽章虚线描边 + 降饱和；
- **跨日连续入选标记**（近 5 个交易日入选次数，行首小徽章，如 ×3）；
- **星标收藏**（localStorage，不依赖后端）：替代三池工作区的"待买"心智，收藏列表可一键筛选；
- 窄屏降级：断点 <1280px 时统计区移至底部、详情变抽屉；<960px 时仅列表 + 详情抽屉；
- 空态与错误态清单：无当日数据 / 加载失败 / 证据 D 级（置灰 + "仅初步观察，估值暂停"）/ stats 缺失（列表降级可用，统计区显示不可用原因）；
- 键盘：↑↓ 切换、Enter 打开报告、Esc 收起。

## 8. 数据与接口

1. 静态产物沿用 `/data/clx-evaluator/runs/<date>/` 模式，新增：
   - `clx-fundamental-ranking`（全量 + 六维等级 + 深析/初评 + 证据等级 + 连续入选次数）
   - `fundamental-analysis/<symbol>.json`、`fundamental-snapshot/<symbol>.json`
   - `fundamental-stats.json`（含**批次质量门**）
2. `latest.json` 扩展：`fundamentalRankingHref` / `statsHref`；
3. `ClxEvaluationPanel` 切换数据源，移除 market 字段展示；`PoolWorkspacePanel` 组件删除，`DailyScreening.vue` 重构为三区。

## 9. 批次质量门（新增）

`fundamental-stats.json` 内置质量门，页面底部状态条展示，任一不通过则顶部出现琥珀色提示：
- 深析完成率 = 100%（前 100 必须全部有 deep JSON）；
- 证据覆盖：A+B 占比、D 级数量（D 级超过阈值提示"本批次大量标的证据不足"）；
- 采集完整率（evidence errors 比例）；
- 重跑一致性：LLM 等级一致率 ≥95%（研发期验收项）。
