函数说明

fqcopilot.dll 支持 3 个平台，内部计算逻辑共享，仅调用接口不同。

通达信函数说明

通过 TDXDLL7(函数号, 参数1, 参数2, 参数3) 调用，共 4 个函数。通达信会自动从 OHLCV 数据填充 HIGH/LOW/CLOSE 序列，因此 Func 2 只需补充 OPEN、VOL 和控制参数。

Func 1：RESET — 重置状态

清除上一只股票的残留数据，每只股票公式计算前必须调用一次。

TDXDLL7(1, 0, 0, 0)

参数均为 0，无返回值。

Func 2：SETPARAMVAR — 设置参数

向引擎传入价格数据或控制参数。第一个参数为参数类型编号，第二个参数为数据。

TDXDLL7(2, 类型编号, 数据, 0)
参数类型编号
编号常量名说明数据
3PARAM_OPEN开盘价OPEN 序列
5PARAM_VOLUME成交量VOL 序列
6PARAM_WAVE_OPT笔参数整数（如 1560）
7PARAM_STRETCH_OPT线段参数整数（通常为 1）
8PARAM_EXT_OPT模型扩展参数整数
9PARAM_MODEL_OPT模型选择整数（如 10001）
WAVEOPT 笔参数编码

4 位整数，由三个字段组合：

WAVEOPT = merge × 10000 + force_count × 100 + bi_mode × 10
位置字段含义取值
万位merge合并未完备笔0 = 关闭，1 = 开启
百位 + 千位force_count强制成笔最小K数10~99（如 15）
十位bi_mode笔模式4 = 新笔，5 = 旧笔，6 = 大笔
1560 → 大笔模式(6) + 15根K成笔 + 不合并
1550 → 旧笔模式(5) + 15根K成笔 + 不合并
11540 → 新笔模式(4) + 15根K成笔 + 合并
MODEL_OPT 模型选择编码
MODEL_OPT = switch_opt × 10000 + model_id
位置字段含义
低 4 位model_id模型编号（0~17）
高位switch_opt策略内部开关
10001 → 模型 S0001，switch_opt = 1

Func 3：SXXXX — 单模型信号计算

根据 Func 2 设置的参数，计算指定模型的买卖信号。

TDXDLL7(3, HIGH, LOW, CLOSE)

返回值：信号值序列。正值 = 买入 负值 = 卖出 0 = 无信号

依赖 Func 2 预设的 OPEN / VOL / WAVEOPT / MODEL_OPT 参数。未设置 MODEL_OPT 时默认计算 S0001。

Func 4：SALL — 批量计算全部模型

一次性计算 18 个模型（S0000~S0017），输出第一个非零信号值。

TDXDLL7(4, HIGH, LOW, CLOSE)

返回值：信号值序列。每个 K 线位置返回优先级最高的非零信号。

需要 Func 2 预设 OPEN、VOL、WAVEOPT 参数。

交易师 / 大智慧函数说明

交易师和大智慧通过 CALCINFO 结构体传入完整的 OHLCV 数据，无需手动调用 SETPARAMVAR 传价格序列。DLL 导出 4 个函数，公式编辑器中通过 "DLL名@函数名"(参数表) 调用。

导出函数说明参数
RUNMODE 返回运行模式 无参，固定返回 1
RESET 重置引擎状态 无参
SETPARAMVAR 设置控制参数 参数1 = 数据序列，参数2 = 类型编号（同通达信 ParamType）
SXXXX 单模型信号计算 参数1 = WAVEOPT，参数2 = STRETCH_OPT，参数3 = EXT_OPT，参数4 = MODEL_OPT
SALL 批量计算全部模型 参数1 = WAVEOPT，参数2 = EXT_OPT
SXXXX / SALL 自动从 CALCINFO 结构体提取 OHLCV 数据，无需额外传入。参数编码与通达信一致。

MT4 / MT5 函数说明

MT4/MT5 通过 #import 直接调用 DLL 导出函数，传入 double 数组。DLL 导出 2 个函数。

导出函数说明
FQ_CLXS 单模型信号计算
FQ_CLXS_ALL 批量计算全部模型

FQ_CLXS — 单模型信号计算

void FQ_CLXS(
    int    count,        // K线数量
    double &out[],       // 输出信号数组
    const double &high[], const double &low[],
    const double &open[], const double &close[],
    const double &vol[],
    int    wave_opt,     // 笔参数（编码同 WAVEOPT）
    int    stretch_opt,  // 线段参数
    int    trend_opt,    // 趋势/扩展参数
    int    model_opt     // 模型选择（编码同 MODEL_OPT）
);

FQ_CLXS_ALL — 批量计算全部模型

void FQ_CLXS_ALL(
    int    count,        // K线数量
    int    model_count,  // 模型数量（最大 18）
    double &out[],       // 输出数组（count × model_count 二维展平）
    const double &high[], const double &low[],
    const double &open[], const double &close[],
    const double &vol[],
    int    wave_opt,     // 笔参数
    int    stretch_opt,  // 线段参数
    int    trend_opt     // 趋势/扩展参数
);

out 数组按行主序存储：out[i * model_count + m] 为第 i 根 K 线、第 m 个模型的信号值。

信号值编码

信号值采用统一编码，可直接解析出方向、模型、触发类型：

signal = direction × (model_id × 1000 + occurrence × 100 + entrypoint)
字段含义取值
direction方向+1 买入，-1 卖出
model_id模型编号0~17
occurrence第几次（含义因模型而异）1~99
entrypoint触发类型1~9

Entrypoint 触发类型

值名称判定逻辑
1结构信号策略模型自身结构判断
2Pin Bar长下/上影线形态
3吞没形态看涨/看跌吞没
4强分型强底/顶分型确认
5MA5 拐头MA5 方向转折
6量价配合量价齐升/跌
7MACD 交叉MACD 金叉/死叉
8~9预留—
